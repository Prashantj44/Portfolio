# 🌌 Prashant Jha — AI & ML Engineer Workspace Portfolio

A high-performance, ultra-responsive **AI Control Dashboard & Space-Themed Interactive Portfolio** built with Vanilla HTML5, CSS3, JavaScript (ES6+), and **Three.js 3D WebGL**. 

Designed with a high-contrast obsidian space aesthetic, dynamic 3D floating planets, starfield parallax, an interactive terminal simulator, and an architectural project vault.

---

## 🌟 Key Features

- **🪐 3D WebGL Space Engine (Three.js)**:
  - Procedural 3D planetary rendering featuring a Saturn-style ringed gas giant, cratered lunar sphere, ice planet, and a 2,800-particle starfield.
  - Real-time mouse and touch-drag depth parallax panning.
- **🎛️ Multi-Pane Workspace Router**:
  - Seamless SPA (Single Page Application) navigation across 6 workspace panes (`Overview`, `About Profile`, `Skills Matrix`, `Project Vault`, `AI Console Engine`, `Transmit Message`).
- **💻 Interactive AI Terminal Console**:
  - High-visibility bash-style console simulator supporting interactive system commands (`whoami`, `skills`, `projects`, `contact`, `clear`, `help`).
- **📂 Architectural Project Vault**:
  - Dynamic category filtering (`AI & ML`, `Mobile Apps`, `Full-Stack`) featuring direct GitHub repository access.
- **📡 Direct Transmit Form**:
  - Integrated contact form dispatching direct notifications to email via FormSubmit API.
- **📱 100% Mobile & Touch Friendly**:
  - Responsive drawer rail, overlay backdrop, smooth scroll behavior, and touch interaction.

---

## 🚀 Tech Stack

- **Core**: HTML5, CSS3 (Custom Design Tokens & Glassmorphism), Modern JavaScript (ES6+)
- **3D Graphics & Animations**: Three.js WebGL Engine, Canvas Rendering
- **Typography**: Google Fonts (`Outfit`, `Fira Code`)
- **Audio Effects**: Web Audio API Synthesizer (Optional Sound Toggle)
- **Deployment & Hosting**: Vercel / GitHub Pages

## 💻 Interactive Terminal Console Commands

| Command | Action / Output |
| :--- | :--- |
| `help` | Lists all available system diagnostic queries |
| `whoami` | Displays developer profile, academic status, and mission |
| `skills` | Outputs full technical AI/ML & full-stack matrix |
| `projects` | Summarizes featured software architectures |

## 🛠️ Local Setup & Development

To run this workspace portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Prashantj44/Portfolio.git

# 2. Navigate to the project directory
cd Portfolio

# 3. Launch local static server (Option A: npx serve)
npx serve -l 8080

# Or (Option B: Python HTTP Server)
python -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.
